
# What is PortSwigger?

* PortSwigger is a cybersecurity company.
* It was founded by Dafydd Stuttard (the author of *The Web Application Hacker’s Handbook*).
* PortSwigger is the creator of **Burp Suite**, the most popular tool for Web Application Penetration Testing.
* They also run the **Web Security Academy**, a free platform where anyone can learn web hacking.

# What are Labs?

* The **Labs** in PortSwigger Academy are **practical challenges**.
* Each lab provides a vulnerable web application.
* Your task is to exploit the vulnerability and confirm the attack.
* Once you succeed, the lab shows a success message.
* These labs are designed to teach you real-world web hacking skills.

# Main Categories of Labs (with simple definitions)

1. **SQL Injection**
   > Injecting SQL queries into input fields to read or change database data. Used to steal or modify sensitive info.

2. **Cross-Site Scripting (XSS)**
   > Injecting malicious JavaScript into a website. Used to steal cookies, sessions, or run unwanted actions.

3. **Cross-Site Request Forgery (CSRF)**
   > Forcing a logged-in user to perform actions without consent. Used to trick users into changing settings or making transactions.

4. **Authentication Vulnerabilities**
   > Weaknesses in login systems. Exploited to bypass login, steal accounts, or break 2FA.

5. **Access Control Vulnerabilities**
   > Gaining access to data or functions you should not see. Used to escalate from normal user to admin.

6. **Clickjacking**
   > Tricking a user into clicking hidden elements. Used to perform actions without the user realizing.

7. **Server-Side Request Forgery (SSRF)**
   > Making the server fetch data from internal or external systems. Used to access private networks or cloud metadata.

8. **XML External Entity (XXE) Injection**
   > Exploiting XML parsers to read files or interact with internal systems.

9. **WebSockets Vulnerabilities**
   > Attacks on real-time communication channels. Used to hijack sessions or manipulate live data.

10. **Business Logic Vulnerabilities**
    > Breaking the intended workflow of an app. Used to get unfair benefits like free products or bypassing limits.

11. **OS Command Injection**
    > Running system commands through input fields. Used to take full control of the server.

12. **File Upload Vulnerabilities**
    > Uploading dangerous files like web shells. Used to hack servers through uploaded files.

13. **Information Disclosure**
    > Application leaks sensitive info like keys, emails, or backups. Attackers use this info for further exploits.

14. **Directory Traversal**
    > Accessing files outside the intended folder. Used to read system files like `/etc/passwd`.

15. **Insecure Deserialization**
    > Exploiting how apps process serialized data. Used to run code or escalate privileges.

16. **Prototype Pollution**
    > Manipulating JavaScript objects. Used to change app behavior or run malicious code.

17. **CORS Misconfigurations**
    > Weak cross-origin rules. Used to steal data from another domain via the victim’s browser.

18. **GraphQL Vulnerabilities**
    > Exploiting GraphQL APIs. Used to extract hidden data or perform unauthorized actions.

19. **Race Conditions**
    > Sending multiple requests at the same time to trick the system. Used for double-spending or bypassing limits.

20. **OAuth and Single Sign-On (SSO) Attacks**
    > Exploiting flaws in login via Google/Facebook etc. Used to take over accounts.

21. **DOM-based Vulnerabilities**
    > Attacks that happen directly in the browser’s JavaScript (DOM). Used for XSS or redirecting users.
