# Cryptographic Issues - Total 5 Hacking Challenges

**Definition:**
Cryptographic Issues occur when an application **improperly implements encryption or hashing**, making sensitive data (like passwords, tokens, or communications) vulnerable to theft or manipulation.

**Common Causes:**
* Weak or outdated algorithms (e.g., MD5, SHA1)
* Poor key management or hard-coded keys
* Insufficient encryption for sensitive data
* Predictable or reused initialization vectors (IVs)
* Insecure storage of encrypted data

**Impact:**
* Data breach (passwords, personal info, tokens)
* Unauthorized access or data tampering
* Loss of confidentiality and integrity

**Examples:**
* Storing passwords in plaintext or using weak hashes
* Using ECB mode for encryption
* Hard-coded API keys in source code
