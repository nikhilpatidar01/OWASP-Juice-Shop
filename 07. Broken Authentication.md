# Broken Authentication - Total 9 Hacking Challenges

**Definition:**
Flaws in authentication that allow attackers to **bypass login, hijack accounts, or steal credentials**.

**Causes:**
* Weak or default passwords
* Predictable session IDs
* Poor password reset mechanisms
* No MFA

**Impact:**
* Account takeover
* Unauthorized access
* Data breach

**Examples:**
* Login bypass
* Session hijacking
* Brute-force attacks

# 2. GDPR Data Erasure

> Under the **GDPR (General Data Protection Regulation)**, **Data Erasure** (also called the *Right to be Forgotten*) means that a person can ask a company to permanently delete their personal data when it is **no longer needed** or if they **withdraw consent**.
> 👉 In short: **GDPR Data Erasure = Your right to ask companies to delete your personal data.**

* **Task** Log in with **Chris' erased user account**.

* **Vulnerable Parameter**

* **User Login** (SQL Injection vulnerability in the login form).

* **Credentials Used**

```text
chris.pike@juice-sh.op'--
123
```

* **Steps to Complete Task**

1. Open the **Login Page** of Juice Shop.
2. In the **Email field**, enter the following payload:

   ```
   chris.pike@juice-sh.op'--
   ``` 
 > (This SQL Injection payload comments out the rest of the query, bypassing authentication).

3. In the **Password field**, type anything (e.g., `123`).
4. Submit the login form.
5. You will successfully log in as **Chris**, even though his account was supposed to be erased.

* **✅ Task Completed:-** GDPR Data Erasure (Logged in with Chris' erased user account).

# 3. Bjoern's Favorite Pet

> This challenge demonstrates how weak **security question mechanisms** can be exploited for account takeover. Many applications allow password reset using personal questions (e.g., *What’s your favorite pet?*). If the answer can be guessed or found through OSINT (open-source intelligence), attackers can reset the victim’s password and hijack the account.

* **Task:-** Reset the password of **Bjoern’s OWASP account** via the Forgot Password mechanism using the original answer to his security question.

**Step-by-Step Solution:**
1. Visit:
   ```
   http://localhost:3000/#/forgot-password
   ```
   Enter: `bjoern@owasp.org` as the email.
2. The security question appears:
   👉 *“Name of your favorite pet?”*
3. Perform OSINT on Bjoern:
   * Visit his Twitter profile: [https://twitter.com/bkimminich](https://twitter.com/bkimminich)
   * Browse through tweets/photos.
4. You’ll find posts showing his cat.
   * Example Tweet: [Tweet 1](https://twitter.com/bkimminich/status/1441659996589207555)
   * Or: [Tweet 2](https://twitter.com/bkimminich/status/1594985736650035202)
5. From these tweets, the cat’s name is revealed as:
   ```
   Zaya
   ```
7. Return to the Forgot Password page.
   * Enter `bjoern@owasp.org` as email.
   * Answer the question: **Zaya**.
   * Provide a new password and confirm it.
8. Click **Change** → Password reset is successful.

* **✅ Successfully Completed:** You solved the **Bjoern’s Favorite Pet** challenge by answering the security question correctly (*Zaya*) and resetting his account password.
