# Injection Total 11 Hacking Challenges
Injection vulnerabilities occur when untrusted input is sent to an interpreter as part of a command or query. This allows attackers to manipulate the execution of commands, SQL queries, or other interpreters, potentially gaining unauthorized access, bypassing authentication, or extracting sensitive data.

**Examples in OWASP Juice Shop:**

* SQL Injection (e.g., logging in as admin without a password)
* NoSQL Injection
* Command Injection in API requests

**Tips to Solve:**

* Look for input fields that interact with databases or commands.
* Try injecting logical statements, special characters, or unexpected input.
* Monitor responses for errors, bypasses, or unexpected behavior.

# 1. Login Admin (Injection)

**Definition:**

> The Login Admin challenge tests your ability to bypass authentication using injection techniques. The goal is to log in as the administrator without knowing the password, typically by exploiting SQL Injection vulnerabilities in the login form.

**Steps to Access:**

1. Open the **Login Page**.
2. Attempt to log in with **administrator credentials** using injection payloads.

   * Example payloads for the username or password field:

     ```text
     ' OR '1'='1
     ' OR 1=1 --
     ```
   * Example full login:

     ```
     Email: nikhil@gmail.com' OR 1=1--
     Password: Test@123
     ```
3. Observe if the login succeeds without the actual password.

```html
http://10.30.30.145:3000/#/login
```
* In Juice Shop, the challenge is automatically marked as solved once you successfully log in as **administrator**.
