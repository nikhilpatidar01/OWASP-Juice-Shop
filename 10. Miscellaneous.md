**Steps to Access:**

* Open the **Dashboard Page**.
* Press **Ctrl+U** to view the page **source code**.

# 3. Bully Chatbot
> The Bully Chatbot vulnerability involves interacting with the application’s support chatbot in a way that reveals hidden or unintended information. In this case, the chatbot can be manipulated into providing a coupon code that should not normally be accessible to the user.

**Steps to Access:**

1. Log in as **Admin**
2. Open the **Site Menu**
3. Navigate to **Support Chat**
4. Type: `hello`
5. Type: `coupon`
6. The chatbot responds with a coupon code

**Result:**
> You successfully receive a coupon code from the chatbot, completing the challenge.

# 4. Mass Dispel
> The **Mass Dispel** challenge is about closing multiple "Challenge solved" notifications in one go, instead of dismissing them one by one.

**Task:**
> Close multiple "Challenge solved" notifications at once.

**Steps to Access:**
1. Go to **Dashboard** where all **Task Completed Notifications** appear.
2. Hold **Shift + X** → this closes multiple notifications together.

**Result:**
> Notifications are closed in bulk, and the challenge is marked as successfully completed. ✅
